== Notes

There are some historical issues with `taskctl` as an independent runner. While `eirctl` (our fork) has addressed many of these, some limitations remain.

=== Global variables cannot be set (Historical Issue)

The README for the original Taskctl project suggested that it is possible to define global variables within the configuration file. However when this was done, an error was generated by the Golang templating engine saying that the variable cannot be found. This issue persists in eirctl and should be considered when designing pipelines.

=== Variables set on a task do not work in a pipeline

Variables can be set on a task as well as when that task is called in a pipeline. It appears that even variables set on a task are not available so have to be duplicated on the call to the task in the pipeline.
